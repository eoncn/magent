## 测试记录要求

- 每次用 fresh worktree/clone，旧新两组交错运行（奇数 old→new，偶数 new→old）。
- 记录真实路由、Worker/Verifier 次数及每次独立验收结果；不准直接把 Agent 自报成功当作 pass。
- 遇到 setup_fail、infra_fail、blocked，保留简要根因，在报告中排除该配对的能力结论；环境恢复后重做。
- 长任务恢复专项：记录 task_id、revision 变化、resume/compaction 后恢复的里程碑、错过的依赖和有界失败升级表现。
